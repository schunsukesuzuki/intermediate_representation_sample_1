# Usage note

This ZIP is a refactored **technical demonstration** derived from the user-supplied
GNN-RAG prototype. It intentionally contains no original proprietary input data,
trained model weights, real patient data, historical artifacts, or copied web
content. It is intended for personal interview preparation and code review.

No open-source license is asserted for the original code or input materials.
Before publishing this repository, confirm ownership and third-party rights.

## Public biomedical data and open-weight models

Hetionet is NOT bundled. The TSV/SIF converter reads only user-supplied input.
Original repository materials carry CC0 language but source databases may have
separate restrictions; review source-specific licenses before publication or
commercial reuse. The lightweight TSV/SIF download excludes per-edge licenses
and provenance attributes present in richer Hetionet releases.

Qwen3 weights are NOT bundled. Users fetch a licensed model via Ollama.
Use only the model variant and license appropriate for the intended environment.
