# v5.1 再評価: 人工的なクラスター情報を隠した合成グラフ

実行日：2026-11-14。JAX CPUを用いた**実測**。Hetionetはこの環境では使用しておらず、全結果は合成グラフのものです。

## 目的

v5のオフライン合成グラフはノード名 `clan0`, `clan1`, ... を持ち、エッジ生成でも同じ潜在クラスターラベルを用いていました。GraphSAGEの文字3-gramノード特徴がこのラベルを読めるため、実際の未知クラスター推定や構造学習の能力を過大評価する恐れがありました。

今回の変更では**クラスタラベルをモデルの入力から取り除きます**。グラフ生成に用いる潜在クラスター構造そのものは維持しますが、GNN・BFS・融合のどの手法にもクラスター所属を渡しません。これは「隠れた構造をグラフから推定する」条件です。構造が完全に無いランダムグラフに置き換えた実験ではありません。

## 変更内容と設計上の制約

- ノード名は `Synthetic disease` / `Synthetic gene` の2種類のみ。`clan`・個別ノード番号・クラスターを識別する文字列は含みません。
- 主実験のGraphSAGE初期特徴は `kind_only`: Disease/Geneの2次元one-hot。**全Diseaseが同一特徴、全Geneが同一特徴**です。名前・ID・隠れクラスター情報は参照しません。
- より厳密な対照では、構造を保ったままノードインデックスを同じ型内で独立にランダム置換しました（permutation seed=20261114）。これにより `ID % 6` から潜在ラベルを推測できるパターンを削除し、BFSのIDによるtie-breakにも人工的規則を持ち込みません。
- 訓練はGraphSAGE + relation vector、25 epoch、seedごとに同一モデル設定。trainのTripleのみでメッセージパッシング・負例サンプリング。Validationでのみ融合重みαを決定。Testを重み選択に使いません。
- GNNとBFSはまったく同じ `(head, relation)` クエリ、型制約候補、保留Tripleで評価。GNNは全候補に対する厳密スコア、BFSは訓練グラフの最短距離と既存のtie-break。Voyager/HNSWのANN近似は混ぜません。
- ノード108、Triple468。保留リンク回復タスクで、医療RAGの回答品質は評価していません。

## 結論

1. **旧v5のGNN単独が大幅に優れるという結論は、人工的なクラスター識別特徴に依存していました。** 同じ3 seed・同じノード番号でclan特徴を除くと、平均MRR@10は 0.3847 → 0.1006 に低下しました。
2. 隠れクラスターをノード特徴から除いた場合、GNN単独はBFSを下回ります。
3. ノード番号も匿名化した厳密対照では、**BFS+GNNもBFSを上回れません**。元の番号の条件で見えた融合の優位性はロバストではありません。
4. この結果は、GNNのモデル能力やHetionet上の実用性能を一般的に否定するものではありません。型だけの特徴、108ノード、25 epoch、関係条件付き損失、ローカルクラスタ合成グラフに限定されます。
5. 次は公開実データ上で同じ3手法・同じ候補集合・複数seedを比較し、独立のノード表現、関係型、Path特徴が本当に付加価値を生むかを検証します。
